# Человеческая основа · этюд 001

Первый рабочий этап Lazy Crazy Chess: анатомическая база взрослого человека для будущих фигур. Обычное мужское телосложение, умеренная мускулатура, контрольный рост 180 см. После сглаживания фактическая высота экспортированной поверхности около 179,8 см.

Это общая основа фракций. Доспехи, оружие, разные лица и боевые сцены появятся на следующих этапах. Материал тела сейчас помогает видеть форму; финальная кожа, волосы и художественный образ ещё не сделаны.

## Открыть и осмотреть

Скачайте `human-base.html` и откройте его в современном браузере. Внутри уже находятся модель, изображение для запасного режима и все зависимости; сеть и локальный сервер не требуются.

- Мышь или один палец вращают модель; колесо и жест двумя пальцами меняют масштаб.
- Кнопки ракурсов показывают тело спереди, сбоку, сзади, в три четверти и лицо.
- Доступны поверхность, сетка и основные суставы.
- Три проверочных движения можно запускать, останавливать и перематывать. Темп — 0,5×, 1× и 1,5×.
- Клавиатура при фокусе на сцене: стрелки — вращение, `+`/`−` — масштаб, `H` — исходный ракурс, пробел — пуск/пауза.
- Анимация запускается только по команде; скрытие вкладки или уход сцены с экрана останавливает её.
- При отсутствии WebGL остаются неподвижный рендер и скачивание GLB.

На телефоне загрузка локальных HTML зависит от приложения, из которого открыт файл. Если встроенный просмотрщик не исполняет JavaScript, откройте скачанный файл в браузере.

## Файлы модели

| Файл | Назначение |
| --- | --- |
| `assets/human-base.blend` | Редактируемое тело, скелет, материалы, действия, сцена освещения и камера |
| `assets/human-base.glb` | Переносимая модель в метрах с текстурой глаз, весами скелета и тремя клипами |
| `assets/model-info.json` | Параметры сборки, источник, контрольные суммы и ограничения |
| `assets/model-checks.json` | Проверки структуры и повторного импорта GLB в Blender |
| `review/neutral.png` | Студийный рендер той же модели |
| `review/viewer-checks.json` | Проверки конечного браузерного просмотра и измерения среды |

Исходная сетка тела содержит 13 380 вершин и 13 378 граней. Скелет — 163 кости, включая кисти, стопы и лицо. Экспорт использует не более четырёх нормализованных влияний на вершину. В Blender сохранена редактируемая контрольная сетка; GLB содержит сглаженную поверхность. Для полной шахматной доски потребуется отдельная оптимизация и уровни детализации.

## Проверочные движения

| Клип | Что проверяем |
| --- | --- |
| `Elbow_Flex` | Сгибание локтей и деформацию предплечий |
| `Ready_Study` | Положение плеч, рук и поворот корпуса перед будущей стойкой |
| `Hand_Close` | Умеренное сгибание пальцев к ладони |

Каждый клип занимает 3 секунды: исходная поза → движение → удержание → возврат. Эти этюды не являются тремя игровыми состояниями взаимодействия. Точный хват древка, давление щитом и парная схватка ещё не созданы. Стопы в этих упражнениях остаются на месте; ходьбы пока нет.

В файле Blender дорожки NLA сохранены выключенными, чтобы документ открывался в исходной позе. Для просмотра отдельного движения включите соответствующую дорожку NLA, оставив остальные выключенными, и проиграйте кадры 0–90 при 30 кадрах/с.

## Воспроизвести сборку

Нужны Python 3.11, Blender Python API 4.5.3 и Node.js с npm.

```bash
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-model.txt
# Исходные данные уже включены. Эта команда нужна для их повторного получения:
.venv/bin/python scripts/fetch_sources.py
.venv/bin/python scripts/build_model.py
.venv/bin/python scripts/model_checks.py
npm ci
npm run build
npx playwright install chromium
npm run verify
```

Сценарий получения данных использует конкретную ревизию MakeHuman. `source/manifest.json` хранит адреса и SHA256 каждого исходника; сборка проверяет их перед использованием.

## Границы проверки

Проверяются размер и структура модели, суммы весов, конечные значения координат, границы клипов и повторный импорт. В конечном HTML проверяются произвольная и обратная перемотка, положение стоп в выбранных моментах, ракурсы, управление, экран 390 px, отсутствие сети, reduced motion и запасной режим без WebGL.

Это не полный аудит столкновений. У временных шорт найдено локальное внутреннее пересечение с телом до 1,42 мм в исходной позе. Корректирующие формы для экстремальных сгибаний, движение мышц, точный хват и ограничения суставов для произвольных внешних анимаций ещё предстоит настроить. Каркас лица включён, но мимические движения не проверялись.

Измерения производительности получены в headless Chromium с программным SwiftShader. Они не являются оценкой FPS телефона. Просмотр рисует неподвижный кадр по изменению состояния; непрерывная отрисовка нужна только во время воспроизведения.
