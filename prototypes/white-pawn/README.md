# Белая пешка · этюд 002

Первый пехотинец Lazy Crazy Chess на общей человеческой основе: взрослый человек ростом 180 см, стальной доспех с холодным серебром и эмалью, белый, ростовой щит и копьё.

Это этап посадки экипировки и постановки движений. Модель ещё не участвует в шахматной партии; парная схватка без победителя, взятие, ходьба и постоянная история ветерана здесь не реализованы.

Файлы релиза: стенд **0.3.0**, модель **0.2.1**. [Мост проверенных релизов из GitHub](../../docs/FLOOT_DEPLOYMENT.md) загружает GLB отдельно и проверяет SHA-256; автономный HTML сохраняет работу без сети. Публикация на сайте выполняется отдельно после полного цикла проверок. Версия открытого сайта показана в интерфейсе и определяется опубликованным manifest.

[Бенчмарк модели 0.2](../../docs/WHITE_PAWN_V02_BENCHMARK.md) задаёт конструкцию брони и креплений. [Аудит модели 0.1.0](../../docs/WHITE_PAWN_REVIEW_2026-10-21.md) сохраняет исходные дефекты плечевых ремней, петли щита и ограниченных движений. В модели 0.2.0 переработаны снаряжение и активные клипы. Структурная проверка и проверка движения экспортированных поверхностей прошли; они не заменяют аудит ремней и визуальную приёмку.

## Открыть

Скачайте `white-pawn.html` и откройте в браузере. Модель, изображение для запасного режима и зависимости встроены в один файл. Сеть и локальный сервер не требуются.

- Мышь или один палец вращают фигуру; колесо или жест двумя пальцами меняют масштаб.
- Ракурсы показывают экипировку спереди, сбоку, сзади, шлем и обе руки крупнее.
- Доступны поверхность, сетка и основные суставы.
- Движения запускаются по команде. Есть пауза, перемотка, шаг ±1 кадр (1/30 с) и темп 0,25× / 0,5× / 1× / 1,5×.
- «Отметить проблему» останавливает движение и фиксирует кадр с ракурсом. Добавьте комментарий и скачайте JSON для восстановления позы или PNG с подписью.
- До 50 замечаний сохраняются в этом браузере. Они не отправляются на сервер; для передачи скачайте файл. JSON принимается для восстановления только при совпадении SHA модели.
- Строка версии различает стенд и геометрию. FPS измеряется только во время воспроизведения видимой сцены.
- При уходе сцены с экрана или скрытии вкладки движение останавливается.
- При отсутствии WebGL доступны сохранённый рендер и скачивание GLB.

На телефоне открывайте скачанный HTML в браузере: встроенный просмотрщик приложения может не исполнять JavaScript.

## Движения

| Клип | Назначение в модели 0.2.0 | Длительность |
| --- | --- | --- |
| `Guard_Breath` | Спокойное движение корпуса в вооружённой стойке | 6 с |
| `Shield_Brace` | Упор щитом: ноги, таз и корпус участвуют в движении; верх, середина и низ щита продвигаются вперёд | 4 с |
| `Spear_Study` | Учебный укол: подготовка копья почти горизонтально, продвижение наконечником вдоль древка и возврат | 4 с |

Имена клипов сохранены для управления и замечаний. Это одиночные этюды: контакт с противником и силы удара не рассчитываются.

[Проверка конечного GLB](review/equipment-checks.json) измеряет вершины поверхностей после скиннинга. В рабочей фазе укола (1,25–1,90 с) наконечник проходит вдоль оси 219,94 мм; отклонение древка от горизонтали по выборке не превышает 5,01°. В фазе упора (0,65–1,65 с) верхняя, средняя и нижняя зоны щита проходят вперёд соответственно 168,37 / 168,60 / 168,31 мм. Максимальное смещение проверенных вершин подошв по трём клипам — 0,147 мм. Эти результаты относятся к GLB с SHA-256 `95249c6f86fe773e4b5408f4350778df050765f67f92cb17d799fb8171858c47`.

Положение таза проверяется проекцией середины тазобедренных суставов на контур опоры подошв. Это геометрический показатель; масса частей тела, центр масс, реакции пола и динамическая устойчивость не рассчитываются. Продвижение наконечника подтверждает траекторию учебного укола, но не физику боя, эффективность удара или удобство суставов.

## Файлы

- `assets/white-pawn.glb` — модель с экипировкой и анимациями для просмотра и переноса.
- `assets/white-pawn.blend` — редактируемая сцена с раздельными деталями, материалами и скелетом.
- [assets/model-info.json](assets/model-info.json), [assets/model-checks.json](assets/model-checks.json) — параметры сборки и структурная проверка конечной модели.
- `scripts/build_pawn.py`, `scripts/pawn_pose.py` — воспроизводимая геометрия, посадка снаряжения и движения.
- `review/viewer-checks.json` — проверка окончательного автономного просмотра.
- [review/equipment-checks.json](review/equipment-checks.json) — проверка опоры стоп, проекции таза, движения копья и щита по поверхностям конечного GLB; успешный отчёт с совпадающим SHA-256 обязателен для выпуска.
- `review/neutral.png` — рендер этой же модели в исходной стойке.
- `src/` — интерфейс и Three.js-просмотр.
- `scripts/build.mjs` — сборка автономного HTML.
- `scripts/verify.mjs` — проверки конечного просмотра в Chromium.

Исходная человеческая модель остаётся отдельно в `../human-base/`. Лицензии MakeHuman, Three.js и вспомогательного кода приведены там же; сборка включает лицензии просмотрщика в итоговый HTML.

## Собрать просмотр

Из корня репозитория:

```bash
cd prototypes/human-base
npm ci
cd ../white-pawn
npm run verify:equipment
node scripts/build.mjs
node scripts/verify.mjs
```

Перед сборкой должны существовать GLB и рендер в указанных выше каталогах. Просмотр использует зависимости соседнего этюда, а готовый HTML полностью автономен.

Проверка использует Chromium, установленный через Playwright. При необходимости выполните `npx playwright install chromium` в каталоге `human-base`.

## Что проверяет просмотр

Проверка сверяет исходную позу GLB с началом движения, длительности клипов, совпадение их концов, обратную перемотку и конечность координат. Дополнительно проверяются ракурсы, управление, отсутствие сети, экран 390 px, режим уменьшения движения и сохранённое изображение при отсутствии WebGL.

Для каждого движения камера рассчитывается по его собственному диапазону поз и остаётся неподвижной во время воспроизведения. Это сохраняет фигуру в кадре без постоянного изменения масштаба.

Измерения времени отрисовки получаются в headless Chromium с программным SwiftShader. Они позволяют сравнивать сборки в одной среде, но не являются оценкой FPS телефона. Проверка просмотра не доказывает отсутствие всех пересечений доспеха и тела.

## Воспроизвести модель

Требуются Python 3.11 и зависимости из `../human-base/requirements-model.txt` (Blender Python API 4.5.3 LTS). Из корня репозитория, в подготовленной среде:

```bash
python prototypes/white-pawn/scripts/build_pawn.py
python prototypes/white-pawn/scripts/model_checks.py
node prototypes/white-pawn/scripts/verify-equipment.mjs
node prototypes/white-pawn/scripts/build.mjs
node prototypes/white-pawn/scripts/verify.mjs
```

Сборка читает сохранённый `human-base.blend` и оставляет его без изменений. В файле белой пешки доспех, шлем, щит и копьё остаются раздельными деталями. Для GLB совместимые части объединяются по семи категориям с общим скелетом. Форма и материалы сохраняются; уменьшается число вызовов отрисовки. Начальная поза GLB совпадает с началом клипа `Guard_Breath`.

## Посадка и границы проверки

Рост тела — 180 см. Щит, копьё и доспех привязаны к скелету; опора стоп и движение оружия проверяются по конечному GLB. Посадка ремней, хват и зазоры брони требуют отдельного аудита поверхностей и контрольных ракурсов согласно [бенчмарку 0.2](../../docs/WHITE_PAWN_V02_BENCHMARK.md).

Проверяются конечные файлы, нормализация весов, длительности и возврат движений, начальная вооружённая поза, повторная и обратная перемотка, осмотр на 390 px и работа без сети. Контрольные ракурсы и крупные планы дополняют численные проверки.

Это первая примерка, а не окончательная игровая модель. Здесь нет полной системы коллизий, мышечной симуляции, динамики ткани и конского волоса. Модель доспеха вымышлена и не заявлена как историческая реконструкция. Ходьба, парные схватки, смена украшений и следы ветерана относятся к следующим этапам. Согласованное движение ног, таза и корпуса поставлено в активных клипах 0.2.0; физическое распределение веса не моделируется. Для одновременного показа 32 фигур потребуется отдельная оптимизация детализации.

Показатели производительности в отчёте получены в headless Chromium с программным SwiftShader; они не описывают FPS реального телефона.

Итог проверки модели 0.2.0: [измерения и контрольные виды](../../docs/WHITE_PAWN_V02_REVIEW.md).
