# Белая пешка · этюд 002

Первый пехотинец Lazy Crazy Chess на общей человеческой основе: взрослый человек ростом 180 см, доспех в цвете слоновой кости с холодным серебром и эмалью, ростовой щит и копьё.

Это этап посадки экипировки и постановки движений. Модель ещё не участвует в шахматной партии; парная схватка без победителя, взятие, ходьба и постоянная история ветерана здесь не реализованы.

После просмотра пользователем выявлены дефекты плечевых ремней, петли щита и ограничения хвата и движений. Текущая геометрия v0.1 ещё требует исправления. [Бенчмарк и требования к v0.2](../../docs/WHITE_PAWN_REVIEW_2026-10-21.md) отделяют подтверждённые дефекты от предложений. Подписи просмотра уточнены: «Тест щита» и «Вынос копья».

## Открыть

Скачайте `white-pawn.html` и откройте в браузере. Модель, изображение для запасного режима и зависимости встроены в один файл. Сеть и локальный сервер не требуются.

- Мышь или один палец вращают фигуру; колесо или жест двумя пальцами меняют масштаб.
- Ракурсы показывают экипировку спереди, сбоку, сзади, шлем и обе руки крупнее.
- Доступны поверхность, сетка и основные суставы.
- Движения запускаются по команде. Есть пауза, перемотка и темп 0,5× / 1× / 1,5×.
- При уходе сцены с экрана или скрытии вкладки движение останавливается.
- При отсутствии WebGL доступны сохранённый рендер и скачивание GLB.

На телефоне открывайте скачанный HTML в браузере: встроенный просмотрщик приложения может не исполнять JavaScript.

## Движения

| Клип | Назначение | Длительность |
| --- | --- | --- |
| `Guard_Breath` | Спокойное движение корпуса в вооружённой стойке | 6 с |
| `Shield_Brace` | Вынос руки и наклон щита; переноса веса и силового упора нет | 4 с |
| `Spear_Study` | Наклон копья из вертикали на 45° и вынос руки; полноценного укола нет | 4 с |

Это одиночные этюды посадки снаряжения. Ноги и таз в этих клипах неподвижны. Боевые движения и согласованная схватка двух фигур требуют отдельной постановки.

## Файлы

- `assets/white-pawn.glb` — модель с экипировкой и анимациями для просмотра и переноса.
- `assets/white-pawn.blend` — редактируемая сцена с раздельными деталями, материалами и скелетом.
- `assets/model-info.json`, `assets/model-checks.json` — параметры сборки и проверки модели.
- `scripts/build_pawn.py`, `scripts/pawn_pose.py` — воспроизводимая геометрия, посадка снаряжения и движения.
- `review/viewer-checks.json` — проверка окончательного автономного просмотра.
- `review/neutral.png` — рендер этой же модели в исходной стойке.
- `src/` — интерфейс и Three.js-просмотр.
- `scripts/build.mjs` — сборка автономного HTML.
- `scripts/verify.mjs` — проверки конечного просмотра в Chromium.

Исходная человеческая модель остаётся отдельно в `../human-base/`. Лицензии MakeHuman, Three.js и вспомогательного кода приведены там же; сборка включает лицензии просмотрщика в итоговый HTML.

## Собрать просмотр

Из корня репозитория:

```bash
cd prototypes/human-base
npm ci
cd ../white-pawn
node scripts/build.mjs
node scripts/verify.mjs
```

Перед сборкой должны существовать GLB и рендер в указанных выше каталогах. Просмотр использует зависимости соседнего этюда, а готовый HTML полностью автономен.

Проверка использует Chromium, установленный через Playwright. При необходимости выполните `npx playwright install chromium` в каталоге `human-base`.

## Что проверяет просмотр

Проверка сверяет исходную позу GLB с началом движения, длительности клипов, совпадение их концов, обратную перемотку и конечность координат. Дополнительно проверяются ракурсы, управление, отсутствие сети, экран 390 px, режим уменьшения движения и сохранённое изображение при отсутствии WebGL.

Для каждого движения камера рассчитывается по его собственному диапазону поз и остаётся неподвижной во время воспроизведения. Это сохраняет фигуру в кадре без постоянного изменения масштаба.

Измерения времени отрисовки получаются в headless Chromium с программным SwiftShader. Они позволяют сравнивать сборки в одной среде, но не являются оценкой FPS телефона. Проверка просмотра не доказывает отсутствие всех пересечений доспеха и тела.

## Воспроизвести модель

Требуются Python 3.11 и зависимости из `../human-base/requirements-model.txt` (Blender Python API 4.5.3 LTS). Из корня репозитория, в подготовленной среде:

```bash
python prototypes/white-pawn/scripts/build_pawn.py
python prototypes/white-pawn/scripts/model_checks.py
node prototypes/white-pawn/scripts/build.mjs
node prototypes/white-pawn/scripts/verify.mjs
```

Сборка читает сохранённый `human-base.blend` и оставляет его без изменений. В файле белой пешки доспех, шлем, щит и копьё остаются раздельными деталями. Для GLB совместимые части объединяются по семи категориям с общим скелетом. Форма и материалы сохраняются; уменьшается число вызовов отрисовки. Начальная поза GLB совпадает с началом клипа `Guard_Breath`.

## Посадка и границы проверки

Рост тела — 180 см; ростовой щит — примерно 133 × 62 см. Диаметр деревянного древка — 25 мм, кожаного хвата и рукояти щита — 28 мм. У щита есть отдельная рукоять и две широкие кожаные петли на предплечье; их крепления доходят до задней поверхности щита. Снаряжение привязано к скелету. Стопы сохраняют опору во всех трёх этюдах.

Проверяются конечные файлы, нормализация весов, длительности и возврат движений, начальная вооружённая поза, повторная и обратная перемотка, осмотр на 390 px и работа без сети. Контрольные ракурсы и крупные планы дополняют численные проверки.

Это первая примерка, а не окончательная игровая модель. Здесь нет полной системы коллизий, мышечной симуляции, динамики ткани и конского волоса. Модель доспеха вымышлена и не заявлена как историческая реконструкция. Ходьба, перенос веса в бою, парные схватки, смена украшений и следы ветерана относятся к следующим этапам. Для одновременного показа 32 фигур потребуется отдельная оптимизация детализации.

Показатели производительности в отчёте получены в headless Chromium с программным SwiftShader; они не описывают FPS реального телефона.
