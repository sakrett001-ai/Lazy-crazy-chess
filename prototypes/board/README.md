# Живые шахматы: доска 0.1

Первый вертикальный срез игры: полная доска 8×8 с классическими правилами, живые пешки и одна сцена взятия. Правила берутся из [chess.js](https://github.com/jhlywa/chess.js) без изменений; анимация только показывает законный ход.

## Как посмотреть

Скачайте [board.html](board.html) и откройте в браузере. Модели и библиотеки встроены, сеть не нужна. Файл весит около 21 МБ.

- Кнопки слева загружают позиции: новая партия, сцена взятия (e4 берёт d5), схватка и оборона.
- Ход делается двумя щелчками: фигура, затем клетка. Подсвечиваются законные ходы и взятия.
- «Чёрные отвечают сами» включает простой ответ чёрных (предпочитает взятие).
- «Замедлить в 2,5 раза» помогает рассмотреть удар.
- Камера вращается мышью; «Вернуть камеру» возвращает общий вид.

## Что работает

- **Законные ходы.** Взятие на проходе, рокировка (ладья идёт своим ходом), превращение в ферзя. Каждая фигура сохраняет своё имя от хода к ходу; на этом позже держится личная история бойца.
- **Поведение пешек по расстоянию до противника.** Далеко от врага пешка стоит в покое. За две клетки от врага она поворачивается к нему и готовится. Рядом с вражеской пешкой начинается фехтование: противники по очереди делают выпады в щит друг друга, и укол останавливается у лицевой поверхности щита. Рядом с более сильной фигурой (конь, слон и старше) пешка уходит в глухую оборону за щитом.
- **Сцена взятия пешки пешкой.** Атакующий разворачивается и подходит наискосок, делает ложный выпад. Защитник поворачивает щит на финт и открывает бок. Следует укол копьём в незащищённую сторону, защитник падает по направлению удара и исчезает, победитель занимает клетку. Сцена длится 4,4 с, без прыжков и акробатики.

## Ограничения прототипа

- Чёрные пешки — та же белая модель 0.4.2 с временной обсидиановой окраской; своя геометрия чёрной пешки будет позже.
- Ладьи, кони, слоны, ферзи и короли — простые заглушки классической формы. Их взятия показаны общей сценой: подход, падение, исчезновение.
- Шагов ещё нет: при ходе пешка скользит по доске, конь перелетает дугой.
- Падение жёсткое, без обмякания тела.
- Пересечения одежды модели 0.4.2 не исправлялись; они перечислены в [геометрическом отчёте пешки](../white-pawn/review/geometry-checks.json).
- 32 фигуры дают около 3,6 млн треугольников. Позы спокойных пешек пересчитываются реже, чтобы доска оставалась плавной на обычной видеокарте.

## Сборка и проверки

```sh
npm install                 # chess.js; three.js берётся из ../white-pawn
npm test                    # правила, состояния пешек, хореография взятия
npm run build               # собирает board.html
npm run verify              # прогон в браузере, кадры фаз в review/
```

Для `verify` нужны установленные `../human-base` (Playwright, esbuild) и `../white-pawn`. Путь к Chrome можно задать переменной `CHROME_PATH`. Проверка идёт с фиксированным шагом 30 кадров в секунду и измеряет наконечник копья и щит на настоящей модели. Это замер анимации, а не физика столкновений.

## Устройство

| Файл | Назначение |
|---|---|
| `src/game.mjs` | Правила через chess.js, постоянные фигуры, события хода (ход, взятие, рокировка, превращение). |
| `src/behavior.mjs` | Состояния фигур по позиции: покой, готовность, фехтование, глухая оборона; очерёдность выпадов. |
| `src/choreography.mjs` | Сцена взятия пешкой по абсолютному времени: фазы, точка удара, финт, падение. |
| `src/actors.mjs` | Пешки на общей модели с окраской фракций, заглушки остальных фигур. |
| `src/board.mjs` | Сцена, доска, выбор хода, исполнение событий, страница проверки `window.livingChess`. |
