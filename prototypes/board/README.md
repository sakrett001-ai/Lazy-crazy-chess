# Живые шахматы: доска 0.2

Первый вертикальный срез игры: полная доска 8×8 с классическими правилами на сгенерированном ландшафте, живые пешки и одна сцена взятия. Правила берутся из [chess.js](https://github.com/jhlywa/chess.js) без изменений; анимация только показывает законный ход.

## Как посмотреть

Скачайте [board.html](board.html) и откройте в браузере. Модели и библиотеки встроены, сеть не нужна. Файл весит около 21 МБ. Сетевая версия в чате сжата до 12,6 МБ.

- Кнопки слева загружают позиции: новая партия, сцена взятия (e4 берёт d5), схватка и оборона.
- Ход делается двумя щелчками: фигура, затем клетка. Подсвечиваются законные ходы и взятия.
- «Чёрные отвечают сами» включает простой ответ чёрных (предпочитает взятие).
- «Замедлить в 2,5 раза» помогает рассмотреть удар.
- Камера вращается мышью; «Вернуть камеру» возвращает общий вид. «Новый ландшафт» строит другую местность вокруг доски.

## Что работает

- **Законные ходы.** Взятие на проходе, рокировка (ладья идёт своим ходом), превращение в ферзя. Каждая фигура сохраняет своё имя от хода к ходу; на этом позже держится личная история бойца.
- **Поведение пешек по расстоянию до противника.** Далеко от врага пешка стоит в покое. За две клетки от врага она поворачивается к нему и готовится. Рядом с вражеской пешкой начинается фехтование: противники по очереди делают выпады в щит друг друга, и укол останавливается у лицевой поверхности щита. Рядом с более сильной фигурой (конь, слон и старше) пешка уходит в глухую оборону за щитом.
- **Шаг вместо скольжения.** Пешка идёт на клетку шагами: опорная стопа стоит на месте, пока тело проходит над ней, корпус наклоняется при разгоне и откидывается при торможении, таз поворачивается за шагающей ногой. В покое пешки переносят вес с ноги на ногу и оглядываются.
- **Сцена взятия пешки пешкой (6,6 с).** Атакующий разворачивается и подходит шагом, взводит удар с весом на задней ноге, делает финт в сторону копья защитника и держит его. Защитник уводит щит за финтом, поворачиваясь от таза, и открывает левый бок. Выпад идёт туда же: передняя нога выходит вперёд, таз опускается и доворачивается, наконечник приходит в бок на высоте пояса. Защитника отбрасывает по удару, корпус складывается вокруг раны, щит опускается, ноги подкашиваются, и он оседает на доску по направлению удара. Победитель гасит отдачу, возвращается в стойку и шагом занимает клетку. Без прыжков и акробатики.
- **Ландшафт.** Клетки — каменные плиты (светлый известняк и тёмный базальт) на гравийной подушке внутри каменного бордюра. Вокруг — вытоптанная земля, холмы с травой, выходы камня на крутых склонах, камни, сосны и лиственные деревья, небо с дымкой. Всё строится из одного числа-зерна, без файлов изображений.

## Как устроено движение

У модели пешки всего три клипа: дыхание в стойке, упор щитом и учебный укол. Ходьбы, финта, попадания и падения в них нет. Поэтому поверх клипа работает процедурный слой тела (`src/motion.mjs`): смещение таза, наклон, боковой наклон и поворот корпуса, распределённые по пяти позвонкам, голова и двухзвенная нога к заданной точке стопы. Слой применяется до того, как мастерская пешки решает руки, поэтому копьё и щит следуют за корпусом. Хореография (`src/choreography.mjs`) задаёт слой как функцию времени, без накопления между кадрами.

Биомеханические проверки в браузере идут по каждому кадру сцены: сгиб колена в пределах 0–140° и только вперёд, стопы не уходят в доску, таз остаётся над стопами, пока боец стоит, опорная стопа при шаге не скользит. Это замеры позы, а не физическая модель; пересечения одежды не проверяются.

## Движения из файлов

Тело пешки можно вести клипом: BVH, файл движений проекта или поза с видео (MediaPipe). Клип переносится на скелет пешки по анатомическим рамкам таза и груди; руки, копьё и щит остаются у снаряжения пешки. Без файлов доска работает на своём слое.

Готова одна сцена из Blender: строевой шаг, выход на клетку, финт и укол копьём в открытый бок с реакцией защитника (`motions/pawn-capture.motion.json`). Её собирает `tools/blender/pawn_capture.py` на настоящем скелете пешки с проверкой суставов по анатомическим пределам. Как открыть клип на доске, пересобрать его и откуда взяты пределы — в [docs/MOTION_IMPORT.md](docs/MOTION_IMPORT.md). Отдельная страница `motion-lab.html` показывает любой клип на четырёх дорожках и распознаёт движение с видео.

## Ограничения прототипа

- Чёрные пешки — та же белая модель 0.4.2 с временной обсидиановой окраской; своя геометрия чёрной пешки будет позже.
- Ладьи, кони, слоны, ферзи и короли — простые заглушки классической формы. Их взятия показаны общей сценой: подход, падение, исчезновение.
- Заглушки фигур скользят по доске, конь перелетает дугой.
- Падение после оседания — поворот всего тела вокруг стоп; руки в падении не подстраховывают.
- Щит и копьё движутся только вместе с корпусом: рука по отдельности не управляется, поэтому щит уводится поворотом корпуса.
- Пересечения одежды модели 0.4.2 не исправлялись; они перечислены в [геометрическом отчёте пешки](../white-pawn/review/geometry-checks.json).
- 32 фигуры дают около 3,6 млн треугольников. Позы спокойных пешек пересчитываются реже, чтобы доска оставалась плавной на обычной видеокарте.

## Сборка и проверки

```sh
npm install                 # chess.js; three.js берётся из ../white-pawn
npm test                    # правила, состояния пешек, хореография взятия
npm run build               # собирает board.html
npm run verify              # прогон в браузере, кадры фаз в review/
npm run verify:motion       # клипы покоя и шага из файла на доске
npm run verify:lab          # лаборатория движений
npm run verify:capture      # взятие из клипов Blender: попадание, суставы, стопы
npm run capture:blender     # пересобрать клип взятия (нужен pip install bpy)
```

Для `verify` нужны установленные `../human-base` (Playwright, esbuild) и `../white-pawn`. Путь к Chrome можно задать переменной `CHROME_PATH`. Проверка идёт с фиксированным шагом 30 кадров в секунду и измеряет наконечник копья и щит на настоящей модели. Это замер анимации, а не физика столкновений.

## Устройство

| Файл | Назначение |
|---|---|
| `src/game.mjs` | Правила через chess.js, постоянные фигуры, события хода (ход, взятие, рокировка, превращение). |
| `src/behavior.mjs` | Состояния фигур по позиции: покой, готовность, фехтование, глухая оборона; очерёдность выпадов. |
| `src/choreography.mjs` | Сцена взятия пешкой по абсолютному времени: фазы, точка удара, финт, оседание и падение; походка. |
| `src/motion.mjs` | Процедурный слой тела поверх клипа: таз, позвоночник, голова, ноги к точкам стоп. |
| `src/landscape.mjs` | Ландшафт вокруг доски, каменные плиты клеток и бордюр. |
| `src/actors.mjs` | Пешки на общей модели с окраской фракций, заглушки остальных фигур. |
| `src/mocap/` | Чтение BVH и файлов движений, позы с видео, перенос клипа на скелет пешки. |
| `src/lab.mjs` | Лаборатория движений (`motion-lab.html`). |
| `tools/blender/` | Сцена взятия пешкой в Blender: план тела, решение на скелете, проверки, клип. |
| `tools/motionbricks/` | Запекание походок crowdbricks (видеокарта NVIDIA) и перевод take в файл движений. |
| `src/board.mjs` | Сцена, доска, выбор хода, исполнение событий, страница проверки `window.livingChess`. |
