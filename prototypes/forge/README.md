# Кузница поверхностей

Процедурные PBR-карты снаряжения на процессоре: numpy и pillow, без видеокарты и без сторонних текстур. Карты бесшовные и задаются в физическом масштабе: тайл стали 250 мм, дерева 200 мм, краски 400 мм, кожи 120 мм.

| Поверхность | Что видно |
| --- | --- |
| Сталь | Лунки от молотка 0,1–0,3 мм, полосы шлифовки, свежие и старые царапины, глубокие риски, точечная ржавчина, грязь в пятнах, побежалость |
| Дерево | Ясень: неравномерные годовые слои вдоль волокна |
| Краска | Краска по доскам 130 мм, сколы до дерева, царапины |
| Кожа | Поры и мелкие складки |
| Лицо щита | Своя карта на каждый щит: износ у кромки по его контуру, вытянутые следы уколов с трещинами, грязь у нижнего края |

## Запуск

```
python3 prototypes/forge/forge.py --out prototypes/forge/maps [--size 1024] [--wear 0.5]
python3 -m unittest prototypes/forge/test_forge.py
```

Для каждой поверхности пишутся `base_color.jpg` (sRGB), `normal.jpg` (OpenGL), `orm.jpg` (R — 1, G — шероховатость, B — металл, как в glTF) и `manifest.json` с размером тайла, средними и хешами. Шов тайла проверяется при запекании: перепад на краю не больше двух средних перепадов внутри карты.

## Как карты попадают в фигуру

`prototypes/white-pawn/scripts/surfaces_blender.py` вызывается при сборке пешки (`build_modular.py`):

- даёт снаряжению второй UV-слой «Surface wear» в метрах позы привязки: древко — цилиндр, клинок — плоскость клинка, лицо щита — плоскость щита, остальное — проекция по осям со сглаженной нормалью, чтобы шов шёл редкой линией;
- строит материалы: карта цвета умножается на цвет материала, шероховатость и металл берутся из ORM, масштаб тайла уходит в GLB как `KHR_texture_transform`;
- рисует карту лица каждого щита по его контуру.

Карты несут только рисунок износа. Цвет фракции задаёт просмотр (`src/surfaces.mjs`): он делит цвет и шероховатость материала на средние карты (`forgeMeanColor`, `forgeMeanRoughness` в extras), поэтому средний цвет щита и стали остаётся тем, что выбран в настройках.

## Ограничения

- Царапины и вмятины не повторяют форму конкретной детали: это рисунок по поверхности, а не следы, рассчитанные по ударам.
- Затенение в углублениях пока не запекается: канал R в ORM равен 1.
- Износ один на комплект (0,5). Отдельный износ для новобранца и ветерана — следующий шаг.
